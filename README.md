## 브랜치 전략
각 레벨별 feature 브랜치를 생성하여 작업을 진행하고, 완료된 작업은 PR을 통해 main 브랜치에 병합했습니다.<br/>
상세 작업 내용은 [PR 내역](https://github.com/WookJaes/spring-advanced/pulls?q=is%3Apr+is%3Aclosed)에서 확인 가능합니다.

- `main`
- `feature/lv0-project-settings`

- `feature/lv2-code-improvement`
- `feature/lv3-entity-graph`
